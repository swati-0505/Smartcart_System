# 🛒 Smart Cart System

## 📌 Overview
An Unsupervised Machine Learning intelligent cart system that processes 
and analyzes product and customer data to support 
smarter shopping decisions.

## 🛠️ Tech Stack
- **Language:** Python
- **Libraries:** Pandas, NumPy, Matplotlib
- **Environment:** Jupyter Notebook

## 📊 Project Workflow
1. Data Loading & Cleaning
2. Exploratory Data Analysis
3. Product & Customer Analysis
4. Insights & Visualization
